# g2rain

下一代 AI 软件开发范式，AI 原生 Agent 平台，开源的企业级 SaaS 底座。

g2rain 以多仓库方式维护平台架构、统一身份与访问契约、前端应用基础、研发工具、部署编排和社区治理。组织级架构、Profile、跨项目 ADR 与项目采用状态以 [g2rain/g2rain](https://github.com/g2rain/g2rain) 为准。

## 当前能力

| 方向 | 说明 |
| --- | --- |
| 架构与治理 | 维护版本化 Profile、跨项目 ADR、项目目录和显式架构例外。 |
| 身份与平台基础 | 已登记统一身份与访问服务，以及网关、前端 Shell/应用的协作契约。 |
| 研发工具链 | 提供官方前端脚手架、后端项目生成与数据库代码生成能力。 |
| 部署编排 | 提供 Docker Compose 环境初始化、生命周期与业务扩展编排。 |
| 社区协作 | 通过 Issues、Discussions、贡献指南、行为准则与安全报告流程开展协作。 |

## 技术栈

**后端**：Java（JDK 25）、Spring Boot 4.0、Spring Cloud、Spring Gateway、MySQL、Redis 等。

**前端**：TypeScript、Vue 3、qiankun（微前端）、Vite、Element Plus 等。
