# g2rain 组织级 GitHub 默认文档

本仓库提供 GitHub 组织范围内复用的公开资料与社区健康文件。它不承载平台实现、项目运行配置、密钥或项目级架构决策；这些内容的事实来源是 [g2rain/g2rain](https://github.com/g2rain/g2rain)。

## 内容

| 位置 | 用途 |
| --- | --- |
| [profile/README.md](profile/README.md) | GitHub 组织主页展示的公开简介。 |
| [CONTRIBUTING.md](CONTRIBUTING.md) | 默认贡献与 Pull Request 协作规则。 |
| [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md) | 默认社区行为准则。 |
| [SECURITY.md](SECURITY.md) | 默认漏洞报告与披露规则。 |

后续可在本仓库增加组织级 Issue/PR 模板、Actions 或其他 GitHub 默认配置。此类配置只应处理跨仓库的协作体验；平台架构、Profile、跨项目 ADR 和项目目录仍由中央文档维护。
